# Source Code

This directory contains scripts, code samples, and utilities for cybersecurity projects.

## Structure

- `project1/` - Network Security scripts
- `project2/` - Web Application Security tools
- `project3/` - Incident Response automation
- `project4/` - Advanced Assessment tools

## Usage

Install dependencies:
```bash
pip install -r ../requirements.txt
```

Run individual project scripts as needed.
